# ZodSharp

Composable, type-safe schema validation for .NET inspired by Zod.

[Documentation overview](Home.md){ .md-button .md-button--primary }
[Get started](Getting-Started.md){ .md-button }

On .NET 11, ZodSharp validates minimal APIs and Blazor forms through the platform's own pipeline: see
[Microsoft.Extensions.Validation](Microsoft-Extensions-Validation.md), [ASP.NET Core Integration](AspNetCore-Integration.md),
[OpenAPI Integration](OpenAPI-Integration.md), [Blazor Integration](Blazor-Integration.md) and
[Localization](Localization.md).
